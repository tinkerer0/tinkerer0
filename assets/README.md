# 프로필 이미지

- `header.svg`, `card-*.svg`: 이 프로필을 위해 만든 정적 벡터 그림. 카드 그림은 프로젝트를 구분하는 장식이며 실제 앱 화면이 아닙니다.
- `avatar.jpg`: 내장 ImageGen으로 생성한 프로필 사진. 짙은 녹색 배경, 아이보리 세라믹 로봇, 민트색 눈, 작은 황동 안테나를 사용했습니다.
- `toolbox.svg`: [Skill Icons](https://github.com/tandpfun/skill-icons)의 Python·Swift·JavaScript·Electron·Git 아이콘. [원본 MIT 라이선스](skill-icons-LICENSE.txt)를 함께 보관합니다.

README의 이미지는 이 저장소에서 제공합니다. 통계 서비스나 정기 실행 workflow는 사용하지 않습니다.
