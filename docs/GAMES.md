## Terminal experiments / 터미널 실험

Python으로 실행하는 게임과 시뮬레이션입니다. 실행 명령은 각 저장소에 있습니다.

| 프로젝트 | 내용 |
| --- | --- |
| [Dodgegame](https://github.com/tinkerer0/dodgegame) | 한 입력이 한 턴이 되는 회피 규칙과 다음 장애물 예고 |
| [Stackgame](https://github.com/tinkerer0/stackgame) | 겹친 폭만 남는 블록 배치와 타이밍 |
| [Sandgame](https://github.com/tinkerer0/sandgame) | 모래·물·불·식물·벌레의 상호작용 |

게임 소스의 이용 조건은 각 저장소를 따릅니다. 소스가 공개되어 있어도 라이선스가 지정되지 않은 프로젝트가 있습니다.
