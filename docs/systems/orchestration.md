# Agent Orchestration

**여러 AI 에이전트와 함께 개발하기 위한 협업 도구**

[프로필](../../README.md) · [Opeld](opeld.md) · [연구 소프트웨어](research.md)

여러 AI 에이전트를 실제 개발 작업에 활용할 수 있도록 협업 도구와 운영 체계를 만들고 있습니다.

## 직접 맡은 범위

- 에이전트 협업 방식과 개발 도구 설계
- 작업 진행과 결과 확인을 지원하는 기능 구현
- 실제 사용 결과에 따른 개선

## 현재 상태

개발 작업에 사용하며 지속적으로 개선하고 있습니다. 현재 구현, 상세 운영 규칙과 내부 실행 자료는 비공개입니다.

이 페이지에는 프로젝트의 목적과 개발 범위만 소개합니다. 공개 작업의 예시는 [done-contract](https://github.com/tinkerer0/done-contract)에서 확인할 수 있습니다. 이 도구는 별도 프로젝트이며, 전체 협업 체계의 구현을 담고 있지 않습니다.
