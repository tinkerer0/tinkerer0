# AI Scientist Lab

**연구 작업을 지원하는 소프트웨어 시스템**

[프로필](../../README.md) · [Opeld](opeld.md) · [에이전트 협업](orchestration.md)

연구자가 자료를 검토하고 분석과 문서 작업을 진행하는 데 필요한 소프트웨어를 설계·개발하고 있습니다.

## 직접 맡은 범위

- 연구 작업에 맞춘 시스템 설계
- 데이터 처리·분석 도구와 작업 환경 구현
- 분석 산출물과 연구 문서를 다루는 기능 개발

## 현재 상태

연구 프로토타입을 개발 중입니다. 연구 판단과 외부 공개는 연구자의 검토를 거칩니다.

소스, 상세 작업 흐름, 연구 데이터와 개별 연구 결과는 비공개입니다. 이 페이지에는 프로젝트의 목적과 개발 범위만 소개합니다.
