# Opeld

**사람과 AI 코딩 도구를 위한 개발 워크스페이스**

[프로필](../../README.md) · [연구 소프트웨어](research.md) · [에이전트 협업](orchestration.md)

여러 AI 코딩 도구와 함께 개발하는 사람이 작업에 집중할 수 있도록 만드는 데스크톱 앱입니다.

## 직접 맡은 범위

- 제품 기획과 시스템 설계
- 데스크톱 앱과 개발 도구 통합 구현
- 실제 사용 환경에서의 동작 확인과 개선

## 현재 상태

macOS 로컬 알파를 개발 중입니다. 일반 배포 전 단계이며, 소스와 상세 구현은 비공개입니다.

이 페이지에는 프로젝트의 목적과 개발 범위만 소개합니다.
