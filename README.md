## 공개 코드와 배포

- **[done-contract](https://github.com/tinkerer0/done-contract)** — 코딩 에이전트의 완료 판정에 실제 검사 명령을 연결한 Python 도구. [설계](https://github.com/tinkerer0/done-contract/blob/main/DESIGN.md)·[테스트](https://github.com/tinkerer0/done-contract/tree/main/tests)·[비교 실험](https://github.com/tinkerer0/done-contract/tree/main/docs/evidence)을 공개했습니다. 현재 실험에서 효과가 입증되지 않았다는 결과도 함께 남겼습니다.
- **[MemoBuddy](https://github.com/tinkerer0/MemoBuddy)** — 데스크톱 펫에 글·그림 메모를 보관하는 앱. [Windows 배포](https://apps.microsoft.com/detail/9mv1clqjv6cx)와 [사용자 지원](https://github.com/tinkerer0/MemoBuddy/issues)을 운영합니다. 공개 저장소는 소개·지원 문서입니다.
